# 🚀 Innovative Projects

A collection of practical Java applications built to solve real-world problems while demonstrating core Java programming and Object-Oriented Programming (OOP) concepts.

## 📌 Projects Included

### 💰 Expense Manager
A simple console-based application to track and manage daily expenses efficiently.

**Features:**
- Add expenses
- Categorize transactions
- Display expense records
- Uses Java OOP principles

---

### 🔐 Secure Password Creator
A utility that generates strong and secure random passwords.

**Features:**
- Customizable password length
- Mix of uppercase, lowercase, numbers, and symbols
- Enhances password security

---

### 🕵️ Text Steganography App
A basic text-based steganography tool for hiding and retrieving secret messages.

**Features:**
- Encode hidden messages
- Decode secret text
- Demonstrates basic data security concepts

---

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Java Time API

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Innovative-Projects.git
   ```

2. Navigate to the project folder.

3. Compile and run any Java file:
   ```bash
   javac ExpenseManager.java
   java ExpenseManager
   ```
